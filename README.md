# Multi-Turn LLM Reasoning & Constraint-Testing Benchmark

An automated framework designed to benchmark Large Language Models (LLMs) on multi-turn reasoning, negative constraint compliance, and hallucination boundary detection.

## Key Features
- **Negative Constraint Verification:** Audits candidate models against explicit exclusion rules.
- **Algorithmic Edge-Case Traps:** Tests code generation logic under strict operational restrictions.
- **STEM Saturation Physics:** Evaluates thermodynamic calculations under sub-atmospheric pressures.
- **Safety Boundary Calibration:** Differentiates necessary industrial engineering instructions from unsafe chemistry advice.
